## 説明(4000字以内)

```
「今日の自分、何%で動けてる?」

脳でんちは、1〜2分のかんたんなテストで“いまの判断力”をセルフチェックするアプリです。
比べる相手は他人の平均値ではなく、あなた自身の全盛期。これまでの最高スコアがそのまま「100%」の基準になります。


■ 1〜2分、ゲーム感覚で終わる

・計算 — かんたんな暗算を、正確に、速く
・ストループ — 文字と色のズレを見抜く、切り替えの速さ
・PVT — 光ったら押すだけ。素の反応速度

3つの結果から総合スコアを出し、「全盛期比 何%」で表示します。


■ 基準は「あなたの全盛期」

年齢別・性別の平均と比べても、自分の調子はわかりません。
脳でんちは、あなたがこれまでに出した最高スコアを100%として、今日を測ります。
比べる相手は、昨日までの自分だけです。


■ 時間帯ごとに基準を持つ

朝と深夜では、そもそも出るスコアが違います。
脳でんちは時間帯ごとに基準を持っているので、「夜だから低いだけ」を調子の悪さと取り違えません。


■ 続けるほど見えてくる

測るたびに履歴が貯まり、推移がグラフでわかります。
「自分はいつ調子がいいのか」が、感覚ではなく記録で見えてきます。


■ 気分に合わせて、3つのモード

・BOOST!! — 短時間で一気に集中を引き上げるスピードゲーム
・RELAX — 呼吸のリズムに合わせて、静かに整える
・トレオタ — 計算・ストループ・PVT を単体で練習できるトレーニング


■ 通信は一切なし。データは端末の中だけ

アカウント登録もログインも不要です。
測定データはすべて端末内にのみ保存され、外部に送信されることはありません。
広告もアクセス解析も入っていないので、機内モードのままでも全機能が使えます。
不要になれば、設定画面からいつでも全データを削除できます。


【ご注意】
本アプリは医療機器ではなく、疾病の診断・治療・予防を目的とするものではありません。
測定結果は医学的な評価ではありません。体調に不安がある場合は医療機関にご相談ください。
```

## App のプライバシー(App Store Connect > App のプライバシー)

- **「データを収集しません」を選択**。
- 根拠: ネットワーク通信を行うコードが存在せず、解析SDK・広告SDK・クラッシュレポートを一切組み込んでいない。
  測定データは端末内 IndexedDB のみに保存される。
- 対応するプライバシーマニフェストを `ios/App/App/PrivacyInfo.xcprivacy` に同梱済み
  (`NSPrivacyTracking = false` / 収集データ・要理由APIとも空)。

```
・本アプリはアカウント登録・ログインを必要としません。起動後すぐに全機能をご確認いただけます。

・本アプリは医療機器ではなく、診断を目的としないことを、オンボーディング画面と設定画面の両方に明示しています。
・結果画面に表示される「BOOST!!」「RELAX」「トレオタ」はいずれもアプリ内の画面へ遷移するものであり、外部サイトへは遷移しません。
```

## スクリーンショット

必須は **6.9インチ iPhone 用のみ**(1320 x 2868 px または 1290 x 2796 px)。
これ1セットを登録すれば、他のiPhoneサイズには自動で流用される。

推奨する5枚の構成:

| # | 画面 | 見せたいこと |
|---|---|---|
| 1 | 結果画面(ゲージが高スコア) | 「全盛期比 何%」という一目でわかる主役 |
| 2 | ホーム画面 | 1〜2分で測れること・導線のシンプルさ |
| 3 | 測定中(ストループ) | 実際の課題の見た目 |
| 4 | 履歴グラフ | 続けると推移が見えること |
| 5 | BOOST!!(または設定のプライバシー説明) | ミニゲーム、または「通信なし」の安心 |

取得方法は [IOS_RELEASE.md](IOS_RELEASE.md) の「6. スクリーンショットを撮る」を参照。
